Case Study / School LMS

Cyrel Learning Center LMS

A school-oriented web application focused on account access, dashboard entry, and structured academic records.

PHP PostgreSQL Supabase HTML / CSS / JS

Functionality

What this web app does

  • Handles login and account access for school users.
  • Provides a dashboard entry point after authentication.
  • Includes password reset and recovery-related pages.
  • Supports school data areas such as announcements, enrollments, academic years, and payments through the project schema.
  • Uses a branded UI so the system feels specific to the institution instead of generic admin software.

Overview

Project summary

This project stands out because it already shows a real application structure in the repo: PHP pages, database connection code, dashboard styling, password reset screens, and a SQL dump with school-related tables.

It is the kind of project I want more of in my portfolio because it combines interface work with practical data-driven functionality.

Your Role

Student developer

My role here is best represented as building and shaping a school web app experience that connects the visual layer with real backend records.

  • Structured the login and entry flow for users.
  • Worked on dashboard-oriented pages and interface styling.
  • Connected the app to a PostgreSQL-backed data source.

Stack

Tools used

  • PHP for server-side logic and page flow.
  • PostgreSQL for the underlying school records.
  • Supabase-hosted connection details in the repo’s database layer.
  • HTML, CSS, and JavaScript for the frontend experience.
